## 2. 🛡️ Google Play Console Declarations

### A. Data Safety Questionnaire (أمان البيانات):
- **Does your app collect or share user data?** -> Select **No** (The app does not collect or share personal user data with third parties).
- **Location Data:** If prompted about location, specify:
  - *Data type:* Approximate & Precise Location
  - *Collected or Shared:* Ephemeral on-device processing only (used for Prayer times & Qibla).
  - *Is data transferred off device?* No (or only for calculating prayer timings, never logged or stored on external servers).

### B. Ads Declaration:
- **Does your app contain ads?** -> Select **No, my app does not contain ads**.

### C. Target Audience and Content:
- **Target Age Groups:** All ages (13+, 18+, Family).
- **Does the app appeal to children?** -> General Audience.

### D. Exact Alarm Permission Declaration (`SCHEDULE_EXACT_ALARM`):
- **Core use case:** Timely religious prayer reminders (Adhan) and scheduled daily Azkar supplications.

### E. Foreground Service Media Playback Declaration:
- **Category:** Audio / Media Playback (Background Holy Quran recitation listening).

## 3. 🚀 Release Build & Signing Instructions

### Step 1: Generate Release Keystore (if not already created)
```powershell
keytool -genkey -v -keystore muslim-companion-release.jks -alias muslim-companion -keyalg RSA -keysize 2048 -validity 10000
```

### Step 2: Build Production Android App Bundle (.aab)
Run the Gradle release bundle task in PowerShell:
```powershell
.\gradlew.bat bundleRelease
```
The resulting Google Play bundle will be located at:
`app\build\outputs\bundle\release\app-release.aab`
